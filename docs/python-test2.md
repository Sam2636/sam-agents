# 🧠 Python Practice Questions with Examples (15)

1. **Count how many vowels are present in a given sentence.**
   🔹 *Example:* `"Learning Python is fun!"` → Output: `6`

2. **Reverse each word in a sentence while keeping the word order the same.**
   🔹 *Example:* `"Hello world"` → `"olleH dlrow"`

3. **Given a list of numbers, find how many are divisible by both 3 and 5.**
   🔹 *Example:* `[15, 30, 10, 9, 45]` → Output: `3`

4. **Print the names of students who scored 50 or more marks using two lists: names and scores.**
   🔹 *Example:* `names = ['Alice', 'Bob', 'Charlie']`, `scores = [45, 75, 60]` → Output: `['Bob', 'Charlie']`

5. **Replace all negative numbers in a list with 0.**
   🔹 *Example:* `[3, -1, 7, -5, 9]` → `[3, 0, 7, 0, 9]`

6. **Find the most frequent character in a given string.**
   🔹 *Example:* `"programming"` → Output: `'g'`

7. **Check if two given strings are anagrams of each other.**
   🔹 *Example:* `"listen"` and `"silent"` → Output: `True`

8. **Remove duplicate elements from a list but maintain their original order.**
   🔹 *Example:* `[1, 2, 2, 3, 1, 4]` → `[1, 2, 3, 4]`

9. **Create a list of squares of all even numbers from 1 to 20.**
   🔹 *Example Output:* `[4, 16, 36, 64, 100, 144, 196, 256, 324, 400]`

10. **Find the second largest number in a list without using built-in sorting.**
    🔹 *Example:* `[10, 40, 30, 20]` → Output: `30`

11. **Count how many words start with a vowel in a given sentence.**
    🔹 *Example:* `"An elephant eats apples under a tree"` → Output: `5`

12. **Check if a given string is a palindrome (reads the same backward).**
    🔹 *Example:* `"madam"` → Output: `True`

13. **Count the frequency of each word in a sentence (ignore case).**
    🔹 *Example:* `"Hello hello world"` → Output: `{'hello': 2, 'world': 1}`

14. **Combine two lists — one with names and another with scores — and display them together.**
    🔹 *Example:* `names = ['Alice', 'Bob']`, `scores = [90, 80]` → Output: `[('Alice', 90), ('Bob', 80)]`

15. **Given a string, remove all special characters and digits, leaving only alphabets.**
    🔹 *Example:* `"H3ll0! Pyt#on@2025"` → Output: `"HllPytone"`
