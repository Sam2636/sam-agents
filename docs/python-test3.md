# 🐍 Python Mixed Interview Practice — Loops, Collections & Built-ins

This set includes **10 theory questions** and **15 coding questions** covering:
> For Loops, While Loops, If/Else, Lists, Tuples, Sets, Dictionaries, Enumerate, Zip, Itertools, Functools, and Built-in Functions.

---

## 🧠 Theory Questions (10)

1. What is the difference between `for` and `while` loops in Python?  
2. How does `break`, `continue`, and `pass` differ in loop control flow?  
3. What is the difference between lists, tuples, and sets in Python?  
4. Explain the difference between shallow and deep copy with an example.  
5. How does `enumerate()` improve readability in loops?  
6. What happens when you modify a dictionary while iterating over it?  
7. What are the advantages of using `zip()` in Python?  
8. How do `functools.reduce()` and `map()` differ?  
9. What are generator expressions and how do they differ from list comprehensions?  
10. Name five useful built-in functions that can be used during iteration and describe their purposes.

---

## 💻 Coding Questions (15)

1. Print numbers from 1 to 50 using a `while` loop.  
2. Using a `for` loop, print all even numbers between 1 and 100.  
3. Print the sum of all numbers divisible by 7 between 1 and 500.  
4. Given a list of names, print all names that start with the letter `A`.  
5. Reverse a list **without using** the built-in `reverse()` or slicing.  
6. Count how many vowels are in a given string using a `for` loop.  
7. Print the squares of all numbers in a list using `map()` and `lambda`.  
8. Given two lists of equal length, combine them into a dictionary using `zip()`.  
9. Using `enumerate()`, print the index and value of each element in a list.  
10. Find all unique elements in a list using a set.  
11. Given a tuple of integers, find the maximum and minimum values manually (without `max()` or `min()`).  
12. From a dictionary of student scores, print the names of students who scored above 75.  
13. Generate all 3-letter permutations of the word `"ABCDEF"` using `itertools.permutations`.  
14. reverse a list using two pointer and linkedlist.  
15. Write a program to count the frequency of each word in a sentence and store it in a dictionary.
